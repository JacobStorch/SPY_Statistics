# SPY_Statistics
For this project, I utilized Python and the Yahoo Finance API to pull 10+ years of daily stock data across all current S&P 500 components. I also pulled basic biographical information about each company. With this data, I utilized Power BI to find the mean CAGR and volatility by sector. From the outputs of the SQL script, I put together a few graphs in Power BI to help visualize the data.
